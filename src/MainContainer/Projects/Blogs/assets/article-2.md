Your IDE is not a black box. Know your IDE shortcuts. It will speed up your development process.

Here are some known shortcuts for Visual Studio Code, using the default Key Scheme.

I challenge you to pick 3 that you have not used before and try them out. I guarantee you will be moving faster when working in Visual Studio Code.

## 🛠️ General & Editing

| Shortcut                  | Description                 |
| ------------------------- | --------------------------- |
| `Ctrl + Shift + P` / `F1` | Show Command Palette        |
| `Ctrl + P`                | Quick Open (go to file)     |
| `Ctrl + Shift + N`        | New window                  |
| `Ctrl + Shift + W`        | Close window                |
| `Ctrl + X`                | Cut line (empty selection)  |
| `Ctrl + C`                | Copy line (empty selection) |
| `Alt + ↑ / ↓`             | Move line up/down           |
| `Shift + Alt + ↓ / ↑`     | Copy line down/up           |
| `Ctrl + Shift + K`        | Delete line                 |
| `Ctrl + Enter`            | Insert line below           |
| `Ctrl + Shift + Enter`    | Insert line above           |
| `Ctrl + Z`                | Undo                        |
| `Ctrl + Y`                | Redo                        |
| `Ctrl + /`                | Toggle line comment         |
| `Shift + Alt + A`         | Toggle block comment        |

## 🔍 Navigation

| Shortcut                        | Description                    |
| ------------------------------- | ------------------------------ |
| `Ctrl + Tab`                    | Cycle through open editors     |
| `Ctrl + -` / `Ctrl + Shift + -` | Navigate backward/forward      |
| `Ctrl + B`                      | Toggle sidebar visibility      |
| `Ctrl + Shift + E`              | Show Explorer                  |
| `Ctrl + Shift + F`              | Global search                  |
| `Ctrl + G`                      | Go to line                     |
| `Ctrl + T`                      | Go to symbol in workspace      |
| `Ctrl + Shift + O`              | Go to symbol in file           |
| `F8` / `Shift + F8`             | Next/previous error or warning |
| `Ctrl + Shift + M`              | Show Problems panel            |

## ✏️ Editing & Formatting

| Shortcut                     | Description                  |
| ---------------------------- | ---------------------------- |
| `Alt + Click`                | Insert cursor (multi-cursor) |
| `Ctrl + Alt + ↑ / ↓`         | Add cursor above/below       |
| `Ctrl + D`                   | Select next match            |
| `Ctrl + Shift + L`           | Select all matches           |
| `Ctrl + F`                   | Find                         |
| `Ctrl + H`                   | Replace                      |
| `Ctrl + Shift + \\`          | Jump to matching bracket     |
| `Ctrl + Space`               | Trigger suggestion           |
| `Ctrl + Shift + Alt + ↑ / ↓` | Expand/shrink selection      |
| `Shift + Alt + F`            | Format document              |
| `Ctrl + K, Ctrl + F`         | Format selection             |

## 🐞 Debugging

| Shortcut             | Description                      |
| -------------------- | -------------------------------- |
| `F9`                 | Toggle breakpoint                |
| `F5`                 | Start/Continue debugging         |
| `Shift + F5`         | Stop debugging                   |
| `F11`                | Step into                        |
| `Shift + F11`        | Step out                         |
| `F10`                | Step over                        |
| `Ctrl + Shift + D`   | Show Run and Debug view          |
| `Ctrl + K, Ctrl + I` | Show hover (e.g. variable value) |

## 📁 File Management

| Shortcut             | Description                       |
| -------------------- | --------------------------------- |
| `Ctrl + N`           | New file                          |
| `Ctrl + O`           | Open file                         |
| `Ctrl + S`           | Save                              |
| `Ctrl + Shift + S`   | Save as                           |
| `Ctrl + K, S`        | Save all                          |
| `Ctrl + W`           | Close editor                      |
| `Ctrl + K, Ctrl + W` | Close all editors                 |
| `Ctrl + \`           | Split editor                      |
| `Ctrl + 1 / 2 / 3`   | Focus into editor group 1 / 2 / 3 |
| `Ctrl + K, ← / →`    | Focus previous/next editor group  |

## 📦 Source Control (Git)

| Shortcut                      | Description                 |
| ----------------------------- | --------------------------- |
| `Ctrl + Shift + G`            | Show Source Control         |
| `Ctrl + Enter` (in SCM input) | Commit                      |
| `F7`                          | Navigate to previous change |
| `Shift + F7`                  | Navigate to next change     |
| `Alt + Click` on file         | Stage or unstage changes    |
